# 月相机械表高度模拟屏保

一个用 PyQt5 制作的模拟机械表表盘屏保程序，包含时分秒针、日期指针和月相显示。

## 效果预览

![屏保截图](Git-LONGINSS-GIT.jpg)

## 功能特点

- 🕐 平滑运动的时、分、秒针
- 📅 日期指针（31天刻度）
- 🌙 月相显示（按空格键手动调整）
- 🖥️ 全屏显示
